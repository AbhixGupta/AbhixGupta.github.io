  📋 3 SIMPLE STEPS TO DEPLOY
═══════════════════════════════════════════════════════════════

STEP 1: Create GitHub Repository
────────────────────────────────
1. Go to: https://github.com/new
2. Repository name: mywebsite
3. Set to: PUBLIC (required for free GitHub Pages)
4. DON'T check "Initialize with README"
5. Click "Create repository"

STEP 2: Deploy Using Script
────────────────────────────
Run this command in your terminal:

    ./deploy.sh

When prompted, enter:
    https://github.com/AbhixGupta/mywebsite.git

The script will automatically:
• Add all files to git
• Create a commit
• Push to GitHub
• Show you next steps

STEP 3: Enable GitHub Pages
────────────────────────────
1. Go to: https://github.com/AbhixGupta/mywebsite/settings/pages
2. Under "Source":
   • Branch: main
   • Folder: / (root)
3. Click "Save"
4. Wait 2-3 minutes

═══════════════════════════════════════════════════════════════
  🌐 YOUR LIVE SITE
═══════════════════════════════════════════════════════════════

After step 3, your portfolio will be live at:

    https://abhixgupta.github.io/mywebsite

(Note: Change "mywebsite" if you used a different repo name)
