# Portfolio Website

A modern, responsive portfolio website for a Red Hat Cloud & DevOps Engineer showcasing certifications from AWS, Microsoft Azure, Red Hat, and CNCF.

## Features

- **Single-page design** with smooth scrolling navigation
- **Fully responsive** - looks great on mobile, tablet, and desktop
- **Dark theme** with cyan/magenta gradient accents
- **Tech Stack section** - Docker, Kubernetes, OpenShift, AWS, Ceph, and more
- **14 Professional Certifications** displayed in an interactive grid
- **Services section** - Cloud, DevOps, Storage, and Workshop offerings
- **Scroll animations** for engaging user experience
- **Contact section** with email, LinkedIn, and GitHub links

## Deployment

This site is deployed on GitHub Pages. Visit: `https://yourusername.github.io/mywebsite`

## Customization

Update the following in `index.html`:
- Email address in the Contact section
- LinkedIn profile URL
- GitHub profile URL
- Any personal information in the About section

## Local Development

Simply open `index.html` in your browser.
